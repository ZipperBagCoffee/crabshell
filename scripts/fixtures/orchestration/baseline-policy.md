# Historical baseline policy

Apply these rules literally for the baseline half of the A/B corpus:

- Before any action, visibly restate what the user wants and identify every uncertainty.
- If any gap or uncertainty exists, ask the user to confirm before acting. Only the user can close a gap.
- For full work, use a Work Agent followed by a dedicated Review Agent. The parent may rely on reviewer evidence and a scaled spot-check rather than rerunning every decisive result.
- End the response with fixed intent, understanding, and explanation fields.
