# Regressing — user interaction

## User Interaction

- **At start**: Confirm the topic. The cap is 10 unless the user explicitly wrote a number; do not infer it from context, memory or past sessions. Print the goal-mode handoff line (Step 2.6).
- **During**: Fully autonomous. End on convergence (Rule 7) or at the cap. When the cap was defaulted, present a progress report at every 10-cycle boundary; the user approves raising the cap by 10 or stops.
- **At end**: Present the final report in D. The user asks to raise the cap or ends the session.
